# Lección 002 — SQL & Databases for Data Science

**Curso de Data Science y Machine Learning**

## Introducción

Material educativo orientado al estudio de SQL y las bases de datos como herramientas fundamentales para el desarrollo de proyectos de Data Science y Machine Learning.

## Objetivos de aprendizaje

- Comprender los fundamentos de las bases de datos.
- Conocer el lenguaje SQL.
- Desarrollar capacidades de consulta y extracción de datos.
- Aplicar SQL en procesos de análisis de datos.
