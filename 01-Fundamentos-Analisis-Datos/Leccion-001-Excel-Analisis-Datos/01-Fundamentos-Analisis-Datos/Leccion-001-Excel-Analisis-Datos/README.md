## 1. Introducción

Microsoft Excel constituye una herramienta ampliamente utilizada para la exploración, transformación, visualización y análisis de datos.

Esta lección aborda sus principales capacidades analíticas y presenta implementaciones equivalentes mediante Python, estableciendo una conexión entre las herramientas tradicionales de análisis de datos y los entornos modernos de Data Science.

## 2. Objetivos de aprendizaje

Al finalizar esta lección, el estudiante podrá:

- Aplicar técnicas de limpieza y validación de datos.
- Identificar y gestionar registros duplicados.
- Transformar variables de texto y fechas.
- Calcular medidas de estadística descriptiva.
- Aplicar funciones lógicas y de búsqueda.
- Construir e interpretar visualizaciones.
- Comprender el funcionamiento de las tablas dinámicas.
- Realizar análisis de escenarios.
- Comprender los fundamentos de la optimización.
- Identificar equivalencias analíticas entre Excel y Python.

## 7. Nota metodológica

Las implementaciones en Python reproducen operaciones y cálculos analíticos equivalentes a los presentados en Excel.

No constituyen una automatización de la interfaz de Excel ni una reproducción completa de los motores Power Query, Power Pivot o DAX.

## 8. Principales aprendizajes

- La calidad de los datos condiciona la confiabilidad de los resultados.
- Las transformaciones deben documentarse y validarse.
- La selección de una técnica analítica depende del problema que se busca resolver.
- Excel facilita la exploración interactiva de datos.
- Python permite automatizar procesos y mejorar la reproducibilidad.
- Ambas herramientas pueden complementarse dentro de un flujo analítico profesional.
