## Presentación

Este curso constituye una iniciativa académica y profesional orientada al desarrollo de conocimientos y capacidades en Data Science, Machine Learning y analítica avanzada, integrando fundamentos conceptuales, metodologías científicas, implementación práctica y aplicaciones empresariales.

Su propósito es facilitar un aprendizaje progresivo, estructurado y reproducible, que permita comprender no solamente cómo implementar modelos y técnicas analíticas, sino también cuándo utilizarlos, cómo evaluarlos y cómo interpretar sus resultados.

## Objetivos del curso

- Desarrollar fundamentos sólidos de Data Science.
- Comprender los principios estadísticos y matemáticos del análisis de datos.
- Dominar herramientas de programación y procesamiento de datos.
- Aplicar técnicas de análisis exploratorio y visualización.
- Implementar algoritmos de Machine Learning.
- Evaluar, interpretar y comparar modelos predictivos.
- Desarrollar proyectos analíticos de principio a fin.
- Vincular las capacidades analíticas con la resolución de problemas empresariales.
- Promover el rigor metodológico y la reproducibilidad de los resultados.

## Destinatarios

El curso está dirigido a:

- Estudiantes universitarios.
- Docentes e investigadores.
- Analistas de datos.
- Profesionales de tecnologías de información.
- Profesionales de negocios.
- Personas interesadas en Data Science y Machine Learning.

## Cómo utilizar este repositorio

1. Seleccionar el módulo y la lección de interés.
2. Leer la guía técnica correspondiente.
3. Descargar o abrir el Jupyter Notebook.
4. Instalar las bibliotecas necesarias.
5. Ejecutar secuencialmente las celdas de código.
6. Analizar e interpretar los resultados.
7. Experimentar con modificaciones en los datos, parámetros y metodologías.

Para instalar las dependencias iniciales:

`pip install -r requirements.txt`
